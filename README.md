# Fishing Log

## Project Overview
Fishing Log is a web application that helps anglers organize fishing trips, record fish catches, track bait and lures, and review fishing statistics.

## Core Features
- Record fishing trips with dates, locations, and conditions.
- Record fish catches with species, weight, and length.
- Track bait and lures used during fishing trips.
- View fishing history and statistics on a dashboard.
- Filter fishing records by date, location, and fish species.

## Technology Stack
- Frontend: React
- Backend: Node.js and Express
- Database: SQLite
- Containers: Docker and Docker Compose
- CI/CD: GitHub Actions
- Deployment: Google Cloud Platform (GCP)

## AI Tools
GitHub Copilot and ChatGPT will assist with coding, debugging, testing, and documentation. Their contributions will be documented throughout development.
